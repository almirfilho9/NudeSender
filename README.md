# NudeSender — Simulador Fictício

Este repositório contém um simulador fictício, de caráter educativo e reflexivo, que representa de forma abstrata a circulação de conteúdos íntimos na internet.

O projeto não envia, recebe ou exibe imagens reais. Nenhum dado pessoal é coletado.

---

## Objetivo

O objetivo é provocar reflexão sobre privacidade digital, percepção de controle e efeitos de escala no compartilhamento online, utilizando uma simulação simples em front-end.

Não há incentivo ao envio de conteúdos íntimos reais.

---

## Como funciona

1. O usuário confirma um consentimento fictício.
2. Um envio simulado é iniciado.
3. O sistema exibe, de forma progressiva e aleatória:
   - aumento de visualizações
   - compartilhamentos simulados
   - alcance geográfico amplo
   - re-visualizações pelas mesmas pessoas

Todos os números e mensagens são artificiais e não representam dados reais.
